# Minecraft API coverage

This is a source-based coverage matrix for the checkout at host **0.61.0**,
SDK/macros **0.59.0**, ABI **1.51.0**, Minecraft **1.21.1**, and NeoForge
**21.1.265**. It records the public surface that exists in this tree, its path
from a Minecraft hook to Rust/WASM, and the limits that remain. It is not a
roadmap or a claim of complete Minecraft mod compatibility. The matrix
tracks the current working tree. The verification section records which test
suites and in-game checks were executed for this checkpoint.

For guest-call rows, the Java host binds named WebAssembly imports through
`ModuleImports`,
which validates import names and signatures and exposes only bindings supplied
by the relevant host adapter. `AbiMemory`
and `AbiCodec`
bound and encode the byte boundary; domain-specific schemas/codecs are cited
where present. Rust `extern` imports and public wrappers are in the cited SDK
files. Registration callbacks and event-export callbacks use their own
documented ABI paths rather than a host import for every operation.

## Status definitions

- **Fully implemented** means the specifically named contract has a host
  implementation, a Rust-facing API where applicable, and tests for its
  boundary. It does not mean all of Minecraft's related features are covered.
- **Partially implemented** means usable end-to-end operations exist, but a
  significant part of the category requested below is absent or unverified.
- **Not implemented** means no public, vertical SJML API for that capability
  was found in the host/ABI/SDK path. A Minecraft resource file that happens to
  describe related data does not count as a runtime API.
- **Technically unsupported** means the current WASM/security architecture
  deliberately excludes the capability, rather than promising a future API.
- **Requires additional research** means this audit did not establish a safe,
  supported NeoForge extension point or a complete inventory for that area.
