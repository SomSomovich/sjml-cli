# Client situational music selection

A client module can subscribe to NeoForge's `SelectMusicEvent` through
`client_music::subscribe_music_selection`. The callback runs synchronously on the physical
client main thread before Minecraft starts or changes situational music. It receives a detached
snapshot of the original selector's sound ID, delay bounds and replacement flag, plus the current
music sound ID when one is playing. It never receives Minecraft objects.

Subscribing requires `client.audio.music`. A replacement sound must also be
registered by this module, which requires `content.register`:

```toml
[[modules]]
id = "main"
path = "modules/main.wasm"
side = "client"
permissions = ["client.audio.music", "content.register"]
```

```toml
[[grant]]
module = "example/main"
capabilities = ["client.audio.music", "content.register"]
```

Provide a typed callback and subscribe from `mod_init`:

```rust
use sjml::{client_music, client_music_selection, mod_init, mod_register, registry,
    ClientMusicSelectionEvent, MusicSelectionDecision, SjmlResult};

#[mod_register]
fn register_content() -> SjmlResult<()> {
    registry::register_sound("night_theme")?;
    Ok(())
}

#[client_music_selection]
fn choose_music(event: ClientMusicSelectionEvent) -> SjmlResult<MusicSelectionDecision> {
    if event.original_sound_id == "minecraft:music.game" {
        MusicSelectionDecision::replace("example:main/night_theme", 100, 400, true)
    } else {
        Ok(MusicSelectionDecision::keep())
    }
}

#[mod_init]
fn initialize() -> SjmlResult<()> {
    client_music::subscribe_music_selection()?;
    Ok(())
}
```

This registers `example:main/night_theme`. Put the matching sound event key
`main/night_theme` in `assets/example/sounds.json` and its OGG file at
`assets/example/sounds/main/night_theme.ogg`.

The callback returns one of three choices:

- `MusicSelectionDecision::keep()` leaves vanilla or an earlier SJML callback's selection alone.
- `MusicSelectionDecision::stop()` sets the event music to `null`, stopping current situational music.
- `MusicSelectionDecision::replace(id, min_ticks, max_ticks, replace_current)` selects a bounded
  replacement. Its sound event must have been successfully registered by the same package and
  module; the sound must also resolve in the active client sound resources.

Replacement delay bounds must satisfy `0 <= min <= max <= 1,200` client ticks. This is separate
from tracked one-shot playback and does not alter music volume or fade a track. `replace_current`
uses Minecraft's `Music` selector behavior for interrupting a different currently playing track.
The subscription can be removed with `unsubscribe_music_selection`; runtime teardown always removes
it. Calls from static registration, server modules, a dedicated server, or the wrong thread fail
closed.

Every callback sees the same input and callbacks run in ascending runtime module ID order. All
subscribers run; the last non-`KEEP` result wins. SJML calls `SelectMusicEvent.setMusic` and does
not cancel the NeoForge event, so other mods' listeners still run under NeoForge's event priority
rules.

The callback ABI export generated by `#[client_music_selection]` is
`sjml_v1_client_music_selection(ptr, len) -> i64`. The imports are
`sjml_client_music_v1.subscribe() -> i32` and `unsubscribe() -> i32`. The schema-v1 input contains
the original sound ID, optional current music ID, original minimum and maximum delay, and original
replace-current flag. The schema-v1 result contains an action code (`0=keep`, `1=stop`, `2=replace`),
optional replacement ID, replacement delay bounds, and replacement flag. The host validates all
strings, action values, delay limits, callback result length, subscription count and exact owner
registration before applying a replacement.

## Manual client check

In a display-backed Minecraft client with audio enabled, register a sound event and OGG asset in a
test module. Subscribe with the callback above and select a replacement while the vanilla game
music is playing. Confirm that the registered replacement starts after the configured delay,
`replace_current = true` interrupts according to vanilla `Music` rules, `keep()` leaves the current
selector untouched, and `stop()` stops situational music. Repeat with an unregistered or another
module's sound ID and confirm that the host rejects that callback result and disables its owner.
Also verify that another NeoForge listener still receives the event because SJML does not cancel
it. Acoustic and priority behavior still require this live client check.
